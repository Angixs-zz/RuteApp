# RuteApp

## Descripción

RuteApp es una aplicación web para organizar viajes en grupo de forma colaborativa.

La aplicación busca resolver el problema de tener la información del viaje dispersa entre mensajes, notas y hojas de cálculo. Permitirá centralizar los participantes, itinerarios, gastos y datos principales de cada viaje.
